How to charge & use our various batteries

## Charging
This depends on the type of battery. For 3S LiPos, you cannot just send power back through the XT60/Deans connector since this will cause the individual cells to become unbalanced over time.

Instead, each LiPo will have a JST connector that is connected to each individual cell and will balance their voltages.

### Main Boat Battery
1. Set variable PSU to 12.6V
2. Plug in Banana Plug <-> XT60 to battery
   - This is fine because the battery has its own BMS which will balance the 3 cells

### LiPo Batteries
1. Set variable PSU voltage
- For 3S batteries set to 12.6V
- For 2S batteries set to 8.4V
2. Plug LiPo battery Deans & JST into rat's nest BMS
- (We should probably get an actual LiPo charger)
3. Plug in BMS deans to PSU

## RC Controller (AA/18650)
Each RC controller has its own batteries. We have chargers for both that will charge individual battery cells.
